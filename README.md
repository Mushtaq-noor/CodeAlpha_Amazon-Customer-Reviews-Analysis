
# Amazon Customer Reviews Sentiment Analysis

## Project Overview
Analyzed 2,000 Amazon customer reviews using Python,
Pandas, and Natural Language Processing (NLP).
Developed an interactive Power BI dashboard to
visualize customer sentiment and feedback patterns.

## Tools and Technologies
- Python
- Pandas
- NLTK
- BeautifulSoup and Scrapy (prior learning)
- Matplotlib
- Microsoft Excel
- Power BI
- DAX

## Project Workflow
1. Loaded a public Amazon reviews dataset.
2. Cleaned duplicate and missing review data.
3. Processed customer review text using NLP.
4. Analyzed positive and negative sentiment.
5. Identified frequently mentioned words.
6. Examined potential complaint topics.
7. Created an interactive Power BI dashboard.

## Key Findings
- Total Reviews: 2,000
- Positive Reviews: 965 (48.25%)
- Negative Reviews: 1,035 (51.75%)
- Average Review Length: 74.76 words
- Quality and service were leading keyword-matched
  potential complaint topics.

These findings apply to the analyzed sample,
not all Amazon customer reviews.

## Dashboard Features
- Total, positive, and negative review KPIs
- Sentiment distribution
- Average review length
- Frequent negative words
- Potential complaint topics
- Interactive sentiment filtering
